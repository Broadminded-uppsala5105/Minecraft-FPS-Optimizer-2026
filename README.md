## 🩺 Troubleshooting

### Minecraft Not Detected
If the tool can't locate your game:
- Click "Settings"
- Choose "Manual Path"
- Navigate to your `%APPDATA%\.minecraft` folder or your custom installation folder
- Select it and click "OK"

### Optimization Doesn't Improve FPS
- Ensure you restarted Minecraft after optimizing
- Try the "Ultra Performance" preset
- Check your graphics drivers for updates from NVIDIA, AMD, or Intel
- Close other programs that use RAM (browsers, Discord, etc.)

### Game Won't Start After Optimizing
- Open Minecraft-FPS-Optimizer
- Click "Restore Defaults"
- If the game still fails, run the tool and use "Emergency Restore" from the Backup menu
